Hearing

Automatic question detection

WishperAI captures the call's system audio — the other people, via WASAPI loopback on Windows — and transcribes it in short chunks through Whisper. Your own microphone is never opened. No virtual audio device, no meeting bot.

It watches that transcript for a question — a rising phrase, a question mark, a starter like "how would you" — followed by a short silence, and drafts an answer on its own. (Transcription uses your Groq or OpenAI key.) 

transcript  ▸ "…and how would you keep that consistent
              across regions?"
detect      ▸ question · trailing silence 410ms
trigger     ▸ draft answer

Languages: English (US / UK / India), Spanish, French, German, Hindi.

Answering

Streaming, in the order you'll use it

The one-line headline arrives first — first person, short, meant to be spoken. Then the three to five talking points. Then, if it's a coding question, a clean implementation with its time and space complexity.

You start talking on the headline and read the rest as it fills in. Copy the whole thing, or just the code, with one click.

Shaping

It knows what kind of question you were asked

Behavioral questions come back as a STAR story — situation, task, action, result — because that's what the interviewer is scoring. Coding questions come back as a solution plus complexity. System design gets structure and trade-offs. Everything else gets a direct, technical answer.

The model layer

Nothing about models is written into the app.

Every provider exposes a /models endpoint. WishperAI calls it when you open Settings, shows you the current list, and picks a sensible fast default. If the model you had saved has been retired, the next request re-fetches the list, swaps in a working one, retries, and remembers the new choice. You never see a dead-model error.

Groq
Fastest. LPU inference, free tier. Best for real-time reading.
OpenRouter
One key, ~400 models incl. free tiers. List pulled live from their API.
Anthropic
Claude — strongest on ambiguous system-design and trade-off questions.
OpenAI
GPT models, JSON-mode streaming.
Local · Ollama
Runs against localhost:11434. Nothing leaves your machine.

Keys & storage

Your key lives in the OS keychain

The API key is written to the Windows Credential Manager / macOS Keychain through the system keyring API — never to a config file, never to disk in plain text. Settings (provider, model, résumé context, language) sit in local storage.

There's no WishperAI account and no server in the path. Requests go straight from your machine to the endpoint you chose. The full privacy story → 

key      ▸ Windows Credential Manager
settings ▸ localStorage (this machine)
prompts  ▸ you → api.groq.com  (direct)
server   ▸ none
