Download

Two minutes from download to first answer.

Free, source-available, no account. You'll need one API key — free tiers are fine.

Prebuilt installers aren't published yet — clone and build it, it's two commands. Star or watch the repo and you'll see the first release when it lands.

What you need

OS
Windows 10 or 11, 64-bit. macOS 13+ on Apple silicon for the mac build.
a model
An API key for Groq, OpenAI, Anthropic or OpenRouter — each has a free tier. Or a local Ollama install, no key.
transcription
A Groq or OpenAI key for Listen. Groq's free tier covers it; enable the Whisper models under model permissions.
audio
Whatever you already use for calls. It reads your default output device — no microphone access, no extra drivers.
disk
~30 MB installed. No background service, no auto-start unless you add it.

First run

The window opens centred, frameless, on top. Drag it by the bar to wherever you want it.

  1. Open Settings, pick a provider

    Click the gear. Choose Groq to start — it's the fastest and the free tier is generous. Paste your key; it goes straight into the OS keychain.

  2. The model fills itself in

    As soon as the key is valid, the model dropdown loads that provider's live list and selects a fast default. You can pick a different one, but you don't have to.

  3. Add your background (optional but worth it)

    Paste your résumé and a few real project details in the context box. Every answer after that is phrased around your actual history.

  4. Hit Listen — or just type

    Listen starts transcription and auto-answers detected questions. Or type into the box and press Enter. During a call, use Ctrl+Shift+T so clicks pass through to your editor.

Keyboard shortcuts

Global — they work even when the call window or your editor has focus.

Ctrl+Shift+H
Hide the overlay completely, or bring it back. The panic button.
Ctrl+\
Collapse to just the top bar; the rest of the window goes transparent.
Ctrl+Shift+T
Toggle click-through — the mouse stops hitting the overlay.
Ctrl+Shift+Q
Quit immediately.

On some keyboards Ctrl+Shift+H clashes; Alt+Shift+H does the same thing.

Build it from source

The client is a Tauri app — a Rust core and a small React front end. If you'd rather compile it yourself and read every line first, that's the intended path for the cautious.

github.com/sheikhMashuk/wishperai

git clone https://github.com/sheikhMashuk/wishperai
cd wishperai/client
npm install
npm run tauri dev      # or: npm run tauri build

Needs Node 20.19+ and a Rust toolchain.
